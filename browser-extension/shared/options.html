Open a model page and press Import to MeshDepot at the bottom right, then press the site's own download button. The import is sent by itself once you stop downloading.
Works on MakerWorld, Printables, Thingiverse and MyMiniFactory.

Settings

Where the imports go.
Address and port of your instance. Saving asks Firefox for permission to contact that host.
In MeshDepot under Account settings → API keys. It is shown once when created.
MeshDepot fetches the file from the link itself, so the copy the browser saves is usually not wanted.
Imported designs are also filed under “Manual Website Import” in MeshDepot, so everything that came in through the extension stays together. Off by default.
